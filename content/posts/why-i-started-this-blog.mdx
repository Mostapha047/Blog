I've been learning to build software for a while now, mostly in private: a notes app here, a half-finished CLI tool there, dozens of tabs of documentation I never fully close. This blog is an attempt to make that process a little more visible, mostly for my own benefit.

## Why write in public

A few reasons pushed me toward this:

- **Writing forces clarity.** If I can't explain a concept in a few paragraphs, I probably don't understand it as well as I thought.
- **A searchable trail.** Six months from now, "past me" will have already solved half the bugs "future me" runs into. This is my own searchable archive.
- **Accountability.** Publishing something, even to a small audience, is a nudge to actually finish exploring a topic instead of abandoning it halfway.

## What you'll find here

Expect short, practical posts about:

1. Things I learn while building side projects
2. Language and framework features I finally understood after fighting with them
3. Mistakes I made and what fixed them

Nothing here is meant to be the definitive guide to anything — just an honest record of learning in progress. If it's useful to anyone else along the way, that's a bonus.

Thanks for reading.
